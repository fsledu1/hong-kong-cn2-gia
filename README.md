## CN2 GIA、CN2 GT、163：三个名词的实际区别

CN2 是中国电信的下一代承载网，AS4809。它内部还分两档。

CN2 GT 只在部分节点走电信的 59.43 精品节点，高峰期照样会堵。CN2 GIA（Global Internet Access）全程走 59.43，回程相当于给数据开了一条专用通道，延迟更低、丢包率极低、晚高峰不显著劣化。作为对照，普通 163 国际线路是 AS4134，走的是大家共用的国际出口，晚上八点到十一点最容易出问题。

香港这条线的现实是：纯血香港 CN2 GIA 的 VPS 普遍带宽小、价格贵。行业里的普遍情况是月付几十美元起步，带宽常常只有几十 Mbps，做这条线的不少还是小商家。原因不复杂，香港机房的 CN2 GIA 进口带宽成本太高，没人敢放开卖。

所以市面上大量标着“香港 CN2 GIA”的产品，实际是“三网直连精品网”：电信走 CN2、联通走 10099 或 9929、移动走 CMI，三家各走各的最优回国路径。延迟通常落在 30 到 50ms，价格只有纯 GIA 的零头。

这两类经常被前排文章混为一谈，买之前要分清自己要哪一个。

## 常见问题

**晚高峰会不会掉速？** CN2 GIA 这条线路存在的意义就是晚高峰不显著劣化，电信联通回程走 59.43 的用户感受最明显。上面那组延迟是全天中位数，没有分时段数据，所以不能直接等同于晚高峰表现。另外 10Mbps 端口本身就可能先成为瓶颈，轮不到线路出问题。

**香港机房需要备案吗？** 不需要 ICP 备案，这是香港相对大陆机房最实际的一个卖点，买完就能上线面向大陆的站点。内容合规仍然要自己把握。

**0.9GB 内存能跑什么？** 静态站、轻量 API、反向代理、几个 Docker 容器都没问题。WordPress 加宝塔面板加 MySQL 会比较紧张，得配 swap 并且控制插件数量。

**能不能装 Windows？** 技术上 KVM 支持，但要先确认授权费用，而且 0.9GB 内存跑 Windows Server 不现实。

**IP 被墙了怎么办？** 公开资料里没有 LightLayer 的换 IP 收费标准，下单前问客服是最稳妥的做法。作为行情参考，DMIT 是每 15 天可免费换一次，DigitalVirt 是 50 元/次。
